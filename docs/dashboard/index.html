What failed, and where

For android.simulateAgpVersionBehavior (experimental, undocumented), the build log gives AGP's own reason: the option android.useAndroidX was removed in AGP 10 behavior. It fails at configuration in app/build.gradle.kts.

Show every flag

A pass does not prove the flag changed anything. Each flag is set alone, to a value chosen from its name. "Failed with this value" is not the same as "incompatible".
